# Security Policy

## Supported versions

Security fixes are made to the latest version deployed from the `main` branch.

## Reporting a vulnerability

Please do not report exploitable vulnerabilities in a public issue. Use GitHub's
private vulnerability reporting for this repository. Include the affected
component, steps to reproduce, and any relevant impact. Do not include real
user data, credentials, or access tokens.

COLLECT-AG is a client-side application. User records are stored in the user's
browser and Google Drive; there is no COLLECT-AG application backend.
